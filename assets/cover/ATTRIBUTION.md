# Cover sources

Portrait: **Arthur Schopenhauer**, photographed by **J. Schäfer**, March 1859.
Source institution: Frankfurt am Main University Library, via
[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Arthur_Schopenhauer_by_J_Sch%C3%A4fer,_1859.jpg).

Commons identifies the photograph as public domain (Public Domain Mark 1.0).
The original JPEG is retained as `schopenhauer-schaefer-1859.jpg`. The cover
uses a crop of that image; no synthetic portrait or colorization is used.

Original cover layout by Ratanajaya, CC BY 4.0. Typography: Arial / Arial Bold,
rendered using installed fonts; font files are not redistributed.

The editable `cover.svg` embeds the original photograph. `build_cover.py`
composes the same layout as a JPEG at 1600 × 2400 pixels.
